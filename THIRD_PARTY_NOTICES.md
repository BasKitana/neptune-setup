# Provenance and distribution boundary

This private personal migration kit bundles configuration templates and NEPTUNE integration scripts from the user's setup work. It does not bundle WezTerm, Herdr, Codex, Claude, FirstMate, Ollama, model weights, third-party skills, executables or package caches. sources.json identifies upstream installation sources; each upstream project retains its own license and notices. Install and inspect upstream packages from their publishers on the destination.

No public open-source license is assigned by this packaging step. Do not assume a right to redistribute third-party binaries or assets; public redistribution and license choice require a separate review. No authentication or machine history is intended for this repository.
