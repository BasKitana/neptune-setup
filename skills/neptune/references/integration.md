# Integration boundaries

Herdr owns terminal topology and recognized agent lifecycle; installed official integrations own native session references. FirstMate owns its task IDs, inboxes and worktrees where supported. NEPTUNE helpers add small display/dispatch/model-policy adapters and a local governance ledger; they are not a new supervisor or provider proxy.

Follow destination instructions and current upstream documentation. Preserve unrelated configuration, existing auth and user work. Never share a live SQLite ledger across Windows/Ubuntu/network/sync filesystems. Model selection is an offline recommendation; no model API is called. Never fake quota, transcript preservation, visible workers or live verification. Third-party tools/skills are installed from sources.json, not bundled here. OpenCode remains removed.
