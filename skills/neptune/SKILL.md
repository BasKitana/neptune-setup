# NEPTUNE v2

Use the existing launcher and native CLI sessions. Work directly by default; delegate only when useful. Never require an Orchestrator role or delegation gate. Do not change the main AI model/effort. Keep native permissions and explicit overrides authoritative.

For local checks/log retrieval/usage evidence, see [local tools](references/local-tools.md). For optional visible workers, read [visible agents](references/visible-agents.md) and [model policy](references/worker-models.md) only when delegating. Workers require a genuine Herdr pane; desktop setup and offline verification do not. No new model/API service or summarizer is needed.

FirstMate owns tracked tasks and compact briefs on supported hosts. Use its installed instructions and actual IDs; do not create a parallel NEPTUNE task ledger. Preserve existing neptune.py and SQLite history for legacy access. Keep SQLite on its owning host's local disk. A stored record is not evidence of a live process.

Keep briefs to goal, current decisions, relevant files, verified check/revision, blocker, next action. Retrieve older details on demand. Preserve session resume, isolated worktrees when needed, meaningful verification, and recovery records. Avoid unchanged polling and duplicate checks. Worker completion claims require inspection and checks.
